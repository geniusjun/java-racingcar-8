# 💪 프로젝트 개요

랜덤 숫자에 의해 전진하며 우승자를 가리는 초간단 자동차 경주 게임을 구현한다.

# 📝 구현 기능 목록

### 자동차의 이름을 입력하라는 안내 문구 출력 기능

    - [x] '경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)'을 출력한다.

### 자동차의 이름을 입력받는 기능

    - [x] 자동차의 이름을 입력받는다.
        - [x] , 기준으로 자동차를 구분하여 저장한다.
            - [x] 자동차의 이름이 5글자 이하인지 검증한다.

### 전진 시도할 횟수를 물어보는 문구 출력 기능

    - [x] '시도할 회수는 몇회인가요?'을 출력한다.

### 전진 시도할 횟수를 입력받는 기능

    - [x] 전진 횟수를 입력받는다.

### 전진하며 각 회차별 결과를 출력하는 기능

    - [x] '실행 결과'를 출력한다.
    - [x] 회차별로 각 자동차가 0~9사이의 무작위 값을 구한 후 4이상이면 전진한다.
    - [x] 회차별 결과를 출력한다.

### 우승자를 출력하는 기능

    - [ㅌ] 최종 우승자를 출력한다. (ex. '최종 우승자 : pobi, jun)
